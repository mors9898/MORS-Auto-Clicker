# MORS Auto Clicker — Windows

A Windows mouse and keyboard automation utility by **MORS**.

> **Beta software:** Windows runtime testing and security signing are not yet complete. Never disable Windows Security to run the app.

## Downloads
After the Windows GitHub Actions build completes, the portable executable is published to [downloads/MORS_Auto_Clicker.exe](downloads/MORS_Auto_Clicker.exe). If that file is not present, check the [Actions tab](../../actions) for build status.

## Features
- Left/right mouse clicks at current pointer or fixed coordinates
- Adjustable interval, start delay and repeat count
- Keyboard key presses, including common special keys
- F6 to toggle; Ctrl+Alt+F12 emergency stop
- Local settings; Discord/TikTok profile links
